# Portfolio

This repository contains my personal portfolio website. It is a static front-end project built to showcase my work, projects, skills, and professional experience in a polished and interactive format.

## What this project does

The site presents:

- a short introduction about me
- a project gallery
- experience highlights
- contact information
- a personalized visual design with animated elements

## Tech stack

- HTML
- CSS
- JavaScript
- Static web assets

## Structure

- `index.html` — main page structure
- `style.css` — styling and layout
- `Assets/` — images, icons, and design assets

## Run locally

Open `index.html` in a browser, or serve it with a local web server:

```bash
python3 -m http.server
```

Then visit `http://localhost:8000`.

## Notes

This website acts as a personal landing page and project showcase for my software engineering work, AI projects, and product design experiments.
